# dawAct4_1


## 1. Descripción del repositorio
Este repositorio contiene la actividad **1.4 Uso avanzado de GitHub** para el módulo de *Desarrollo de Aplicaciones Web*.  
Aquí practicarás Markdown, GitHub Pages y cómo publicar contenido estático.

### 1.1 Objetivos
- Aprender sintaxis básica y avanzada de Markdown.
- Desplegar el contenido con **GitHub Pages**.
- Comprobar imágenes, CSS y JavaScript estático.
